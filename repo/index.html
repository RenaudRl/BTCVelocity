BTC Studio Repository

Dépôt Maven unifié des APIs du réseau Born To Craft — proxy BTC Velocity et serveur BTC-CORE.

Ajouter le dépôt

Gradle (Kotlin DSL)

repositories {
    maven("https://borntocraftstudio.net/repo/")
}

Maven

<repository>
    <id>btcstudio</id>
    <url>https://borntocraftstudio.net/repo/</url>
</repository>

BTC Velocity API dev.btc.velocity:api:0.1

API du proxy Velocity haute performance (cluster, queue, bridge, permissions).

Gradle

dependencies {
    compileOnly("dev.btc.velocity:api:0.1")
}

Maven

<dependency>
    <groupId>dev.btc.velocity</groupId>
    <artifactId>api</artifactId>
    <version>0.1</version>
    <scope>provided</scope>
</dependency>
